## 🚀 1. GitHub Pages 1분 무료 호스팅 배포 가이드

누구나 접속할 수 있는 웹사이트 주소(`https://<내아이디>.github.io/<저장소이름>/`)를 무료로 만드는 방법입니다.

### 1단계: GitHub 새 저장소 생성
1. [GitHub](https://github.com/)에 로그인합니다.
2. 우측 상단의 **`+`** 아이콘을 누르고 **`New repository`**를 클릭합니다.
3. 설정 입력:
   * **Repository name**: `jeju-trip` (원하는 이름 입력)
   * **공개 설정**: 반드시 **`Public`** 선택 *(※ Private은 유료 계정만 무료 웹 호스팅이 지원됩니다)*
4. 맨 아래 초록색 **`Create repository`** 버튼을 누릅니다.

### 2단계: 프로젝트 파일 업로드 (2가지 방법 중 편한 것 선택)

* **방법 A. 웹 브라우저에서 드래그 앤 드롭 (가장 쉬움)**:
  1. 생성된 저장소 빈 화면에서 **`uploading an existing file`** 링크를 클릭합니다.
  2. 내 컴퓨터의 `jeju-balance-game` 폴더 안에 있는 모든 파일/폴더(`index.html`, `css`, `js`, `backend`, `docs`, `README.md`)를 통째로 브라우저 사각형 영역으로 끌어다 놓습니다.
  3. 업로드가 완료되면 화면 하단의 초록색 **`Commit changes`** 버튼을 누릅니다.

* **방법 B. 터미널(Git) 명령어로 한 번에 올리기**:
  ```bash
  git remote add origin https://github.com/<내깃허브아이디>/jeju-trip.git
  git branch -M main
  git push -u origin main
  ```

### 3단계: Pages 웹 호스팅 켜기
1. 저장소 상단 탭 메뉴에서 **[Settings]** (톱니바퀴)를 클릭합니다.
2. 좌측 메뉴에서 **[Pages]**를 클릭합니다.
3. **Build and deployment > Branch** 항목에서:
   * `None`으로 되어 있는 드롭다운을 **`main`**으로 변경합니다.
   * 바로 옆 폴더는 **`/(root)`** 그대로 둡니다.
   * 우측의 **[Save]** 버튼을 클릭합니다.
4. 약 1분 후 새로고침하면 상단에 **`Your site is live at https://<내아이디>.github.io/jeju-trip/`** 라는 녹색 안내 박스가 뜹니다.
5. 이 주소를 카카오톡으로 민아에게 보내주면 끝납니다!

## 🤫 2. Google 스프레드시트 무음 수신 배포 가이드

민아가 웹앱에서 [선택 완료!]를 눌렀을 때, 로딩창 없이 내 구글 시트에 몰래 1행씩 차곡차곡 누적되는 백엔드 연동법입니다.

### 1단계: 구글 시트 및 Apps Script 생성
1. 브라우저 주소창에 [https://sheets.new](https://sheets.new)를 입력하여 새 스프레드시트를 만듭니다.
2. 시트 좌상단 파일명을 `11월 제주 여행 선택 결과`로 변경합니다.
3. 상단 메뉴에서 **[확장 프로그램] ➔ [Apps Script]**를 클릭합니다.

### 2단계: 수신 코드 붙여넣기
1. 편집기에 적힌 기본 코드(`function myFunction() ...`)를 전부 지웁니다.
2. 우리 프로젝트의 `backend/google-apps-script.js` 파일 전체 내용을 복사하여 붙여넣습니다.
3. 상단의 **[디스켓 아이콘(저장)]** 또는 `Ctrl + S`를 눌러 저장합니다.

### 3단계: 웹 앱으로 배포 (⚠️ 권한 설정 필수 확인)
1. 우측 상단의 파란색 **[배포] ➔ [새 배포]**를 클릭합니다.
2. 좌측의 톱니바퀴 아이콘을 누르고 **[웹 앱(Web App)]**을 선택합니다.
3. 설정값을 다음과 같이 지정합니다:
   * **설명**: `제주 여행 수신`
   * **다음 사용자 권한으로 실행**: **`나(내 계정)`**
   * **액세스 권한**: **`모든 사용자 (Anyone)`** *(⚠️ 필수! '나만'으로 두면 민아가 보낼 때 차단됩니다)*
4. 하단의 **[배포]** 버튼을 누릅니다.
5. *(최초 1회 권한 승인 창이 뜨는 경우)*:
   * **[액세스 승인]** 클릭 ➔ 내 구글 계정 선택
   * "Google에서 확인하지 않은 앱" 경고가 뜨면 좌측 하단의 **[고급(Advanced)]** 클릭 ➔ **`[제목 없는 프로젝트](으)로 이동(안전하지 않음)`** 클릭 ➔ **[허용(Allow)]** 클릭.

### 4단계: 발급된 URL을 웹앱에 입력
1. 배포가 완료되면 화면에 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)이 표시됩니다. **[복사]**를 누릅니다.
2. 우리 프로젝트의 `js/webhook.js` 파일을 열고 9행의 빈칸에 붙여넣습니다:
   ```javascript
   export const SECRET_WEBHOOK_URL = "여기에_복사한_URL_붙여넣기";
   ```
3. 저장 후 GitHub에 커밋/푸시하면 즉시 연동 완료!
   * 이제 민아가 선택을 완료하면 구글 시트에 오렌지색 헤더와 함께 1행씩 깔끔하게 실시간 기록됩니다.
